# Farmer App Native (Expo)

Scaffolded Expo React Native app for farmer/vegetable dealer finance & sales.

Quick start (Windows PowerShell):

```powershell
cd "D:\01Boss\06React\farmer-app-native"
npm install
npx expo start
```

Notes:
- This scaffold includes `Login`, `Dashboard`, `Transactions`, `Finance`, `Inventory`, and `Customers` screens with navigation.
- Data persistence uses `@react-native-async-storage/async-storage`.
- If you don't have Expo CLI installed, the `npm install` step will add required packages; you can also run `npx expo start`.
